# Стратег Фабрики продуктов

ИИ-агент, который ведёт руководителя цифрового продукта от размытого запроса до согласованных продуктовой и коммуникационной стратегий — с проверяемыми источниками у каждого вывода.

Работа команды для номинации «ИИ-проект» MGIMO AI Challenge (задание МегаФона). Срок сдачи — 22 ноября 2026.

## Что где

| Папка | Что там |
|---|---|
| `strateg/` | Сам агент: инструкции, знания, навыки, скрипты, проекты. Эту папку открывают в Cursor, Claude Code или Codex |
| `docs/CASE.md` | Задание и критерии оценки |
| `docs/CONTRACT.md` | Форматы данных между частями агента |
| `docs/COMMS.md` | Как переписываются ИИ-помощники команды |
| `TASKS.md` | Задачи, владельцы, сроки, журнал решений |
| `team-directory/` | Кто есть кто |
| `bench/` | Сравнение агента с обычным чатом |
| `submission/` | Материалы сдачи: видео, PDF |

## Как подключиться участнику команды

1. Прими приглашение в репозиторий и склонируй его.
2. Поставь GitHub CLI и войди: `gh auth login`.
3. Открой папку репозитория (корень, не `strateg/`) в своём инструменте и напиши помощнику:

```text
Меня зовут <Имя>, мой GitHub — <логин>.
Прочитай AGENTS.md и всё, что в нём перечислено.
Отметься в канале агентов и возьми мою первую задачу из TASKS.md.
```

Появится после задач T1 и T11 — см. `strateg/README.md`.
