## Правила для любого ИИ-помощника

1. Определи своего человека по его сообщению или GitHub-логину. Неясно — спроси; не угадывай по нику или имени компьютера.
2. Различай человека и инструмент: `Ника-Claude` и `Ника-Codex` — помощники одного человека.
3. Подпись в `TASKS.md` и в канале: `<Имя>-<ИИ>`, инструмент фактический. Сейчас в команде: `Ратмир-Claude`, `Влад-Claude`, `Ника-Codex`.
4. Не назначай задачи другим и не меняй чужие строки без поручения.

## Сообщение для подключения своего ИИ

Стартовое сообщение — в корневом `README.md`, раздел «Как подключиться участнику команды». Помощник выполняет процедуру «Первый сеанс» из `AGENTS.md` и не начинает работу без слова «начинай».
