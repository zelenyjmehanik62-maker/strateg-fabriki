# Скрипты агента

Владелец — Ратмир (T2). Python 3.9+, только стандартная библиотека. Запуск из папки `strateg/`.

Команды, на которые опирается `AGENTS.md` (реализация — T2):

| Команда | Что делает |
|---|---|
| `strateg.py status [проект]` | Список проектов или где остановился проект и что дальше |
| `strateg.py new <проект>` | Создать папку проекта по шаблону |
| `strateg.py source <проект> …` | Добавить источник в `sources.jsonl` |
| `strateg.py claim <проект> …` | Добавить утверждение в `evidence.jsonl` |
| `strateg.py revoke <проект> E-012 …` | Отозвать или заменить утверждение |
| `strateg.py log <проект> …` | Запись в журнал: действие, инструмент, минуты, стоимость |
| `strateg.py step <проект> …` | Обновить `state.json`: шаг и следующее действие |
| `strateg.py check <проект>` | Проверка реестра и ссылок в результатах |
| `strateg.py impact <проект> E-012` | Какие выводы и решения затронуты |
| `strateg.py cost <проект>` | Сводка времени и расходов |

Форматы файлов — `../../docs/CONTRACT.md`.
