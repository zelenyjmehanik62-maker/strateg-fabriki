# Пример «Полка»: пробная задача для агента

Готовый набор, на котором можно пройти весь путь агента — от размытого запроса до стратегий. Мы сами отлаживаем на нём Стратега.

**Сервис «Полка» вымышлен.** Его внутренние цифры, записка, обращения и экран придуманы и помечены как учебные. Сведения о рынке и конкурентах — настоящие, из открытых источников, с адресами и датой получения.

## Как запустить

1. Откройте папку `strateg/` в Claude Code, Cursor или Codex.
2. Отправьте агенту текст из [запрос.md](запрос.md).
3. Агент создаст проект в `projects/`, скопирует туда материалы и поведёт вас по шагам. Отвечайте за руководителя продукта; всё нужное есть в записке.

## Материалы

| Файл | Вид | Откуда |
|---|---|---|
| `записка-руководителя.docx` | документ Word | учебный: продукт, проблема, что пробовали, ограничения |
| `показатели-подписки.xlsx` | таблица Excel, 4 листа | учебная: когорты, каналы, поведение в пробный период, причины отмены |
| `обращения-в-поддержку.csv` | таблица CSV | учебная: 14 обезличенных обращений за сентябрь |
| `экран-оформления-подписки.png` | снимок экрана | учебный макет экрана оплаты |
| `рынок-итоги-2025.md` | выписка с сайта | New Retail, 31.03.2026 |
| `рынок-первый-квартал-2025.md` | выписка с сайта | Retail.ru, 30.05.2025 |
| `конкурент-литрес-подписка.md` | выписка с сайта | страница «Литрес Подписки», 14.11.2026 |
| `конкурент-яндекс-плюс.md` | выписка с сайта | справка «Яндекс Плюса», 14.11.2026 |

Учебные файлы собираются скриптом `src/make_materials.py`, экран — из `src/paywall.html`.

Что именно этот набор проверяет в агенте и какие выводы мы считаем верными, описано отдельно — в `bench/cases/polka.md` в корне репозитория. Агенту этот файл не показывайте.
