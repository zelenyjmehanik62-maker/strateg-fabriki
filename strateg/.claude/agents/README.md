# Дополнительные помощники

Два узких помощника, не новая обязательная ступень процесса:

- `respondent` - синтетическая роль с чистым контекстом. Передавать только карточку и нейтральные вопросы; не весь проект и не гипотезы. Ответы - только synthetic, не спрос и не факты о пользователях.
- `document-reader` - извлечь сведения по вопросам из большого текста, не загружая его целиком координатору. На малом материале читать напрямую. Координатор проверяет цитаты, сохраняет исходный источник и сам решает, что регистрировать.

В Claude Code конфигурации находятся рядом. В Codex использовать доступный механизм отдельного помощника с чистой историей (`fork_turns="none"` в среде измерения); передавать те же ограниченные входы, не весь разговор. Если среда не обеспечивает отдельный контекст, не заявлять изоляцию: использовать прямое чтение или явно отметить незащищённую модельную беседу.

Это ограничение инструкции и передачи контекста, не файловая песочница: инструмент Read технически может иметь более широкий доступ. Не передавать секреты и чужие закрытые материалы. В измерении использованы только собственные синтетические файлы.

Замер и исходные ответы: `../../../bench/subagents/README.md`. Помощники не обязательны: у отдельного читателя не показан выигрыш в точности, у респондента не показано уменьшение фактических утечек (оба режима не раскрыли контрольный маркер). Польза - ограничение переданного контекста; затраты и переносимость проверяются отдельно.
