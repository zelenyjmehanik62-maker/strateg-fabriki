# Живое демо в Codex на Windows

Учебный пример от организаторов «Связь для близких и собственных устройств». В исходной записи рабочая папка называлась `semya-preduprezhdenie`. Здесь собрана версия для проверки и сдачи. Пять частей собраны из результатов прогона в [document.md](document.md).

- [Краткая сводка](summary.md), [варианты](options.md), [продуктовая стратегия](strategy-product.md), [коммуникационная стратегия](strategy-comms.md), [план проверки](verification.md).
- [Выдержки брифа с привязкой к страницам](materials/brief-excerpts.md). В реестре сохранены исходные ссылки на страницы.
- Связанный расчёт — `python projects/demo-brief/calc/linked_model.py` из папки `strateg/`.
- Проверка — `python tools/strateg.py check demo-brief` из той же папки.

Пользователь согласовал доработку предупреждения. Для решения о пилоте ещё нужны данные и смета. Денежный расход демо не измерен.
