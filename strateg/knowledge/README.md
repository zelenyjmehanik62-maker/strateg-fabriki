# Методические знания

Как делать работу хорошо — в отличие от навыков (`skills/`), где описано, что делать по шагам. Агент читает файл, когда он нужен для текущего вопроса, и не меняет его.

| Файл | О чём | Когда читать |
|---|---|---|
| `methods.md` | Какой метод взять под решающий вопрос | Составляя план исследования |
| `jtbd.md` | Работа клиента: ситуация, цель, альтернатива, барьер | Вопросы «кто клиент», «почему приходит и уходит» |
| `journey.md` | Путь клиента и воронка: где теряются люди | Вопросы «где теряем», «почему не доходят до оплаты» |
| `competition.md` | Альтернативы и конкуренты, включая бездействие | Вопросы «с кем соревнуемся», «чем отличаемся» |
| `unit-economics.md` | Юнит-экономика и сценарии | Вопросы «окупается ли», «можно ли снизить цену», «запускать ли» |
| `sources.md` | Открытые источники: где искать и как им доверять | Поиск данных в сети |
| `quality.md` | Чем хороший результат шага отличается от плохого | Перед тем как показать результат шага человеку |
