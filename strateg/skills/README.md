# Навыки

Навык — пошаговая процедура для одного шага работы агента. Агент читает навык перед шагом (см. таблицу в `../AGENTS.md`) и не меняет его.

| Навык | Шаг | Что даёт |
|---|---|---|
| `frame` | 1. Постановка | `brief.md` — тема превращена в решение |
| `collect` | 2. Материалы | реестр источников и первых утверждений |
| `research` | 3. Исследование | `plan.md`, `findings.md` с разделом «Чего мы не знаем» |
| `options` | 4. Варианты | `options.md` — не меньше трёх вариантов с возражениями |
| `strategy` | 5. Стратегии | продуктовая и коммуникационная стратегии, таблица согласованности |
| `verification` | 5. Стратегии | `verification.md` — план проверки допущений |
| `follow` | 6. Сопровождение | решения, обзор оснований, пересмотр при новых данных |

Дополнительные навыки (`interview`, `ux`, `data`) — задача T6.

Формат навыка: когда применять → что читает и пишет → шаги → вид результата → чего не делать → проверка результата. Навык не повторяет общие правила из `AGENTS.md` и пишет только в папку проекта.
