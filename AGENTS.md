# Инструкции для ИИ-помощников команды

Этот файл читают Codex, Cursor и другие инструменты. Правила одни для всех и лежат в `CLAUDE.md`.

Перед началом работы прочитай целиком:

1. `CLAUDE.md` — командные правила, зоны ответственности, запреты.
2. `team-directory/README.md` — кто есть кто и как подписываться.
3. `TASKS.md` — задачи, владельцы, зависимости.
4. `docs/CASE.md` — задание МегаФона и критерии оценки.
5. `docs/CONTRACT.md` — форматы данных между частями.
6. `docs/COMMS.md` — канал переписки агентов (issue #1). Читай канал сам по этим правилам.

Сопоставь своего человека по имени из его сообщения или по GitHub-логину. Не знаешь — спроси. Не придумывай соответствия и не назначай задачи другим.

В корне репозитория ты помощник разработчика. Папка `strateg/` — продукт со своими инструкциями: ты их разрабатываешь, а исполняешь только по просьбе человека прогнать агента.
