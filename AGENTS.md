# Инструкции для ИИ-помощников команды

Этот файл читают Codex, Cursor и другие инструменты; Claude Code получает его через `CLAUDE.md` и `.claude/rules/`. Правила одни для всех.

## Первый сеанс — строго по порядку

1. **Определи своего человека** по имени из его сообщения или по GitHub-логину (`team-directory/README.md`). Не знаешь — спроси. Не угадывай.
2. **Прочитай целиком:**
   1. `CLAUDE.md` — правила работы, запреты, зоны;
   2. `TASKS.md` — особенно раздел «Что делать сейчас» вверху: там очередь задач твоего человека;
   3. `docs/OVERVIEW.md` — что мы делаем и где сейчас стоим;
   4. `docs/CASE.md` — задание МегаФона и критерии оценки;
   5. `docs/CONTRACT.md` — форматы данных;
   6. `docs/COMMS.md` — канал переписки помощников;
   7. `team-directory/README.md` — кто есть кто.
3. **Сделай `git pull --rebase`** и прочитай последние сообщения канала (команда в `docs/COMMS.md`).
4. **Отметься в канале:** `[<Имя>-<ИИ> → все] online`.
5. **Доложи человеку коротко — до любой работы:**
   - что за проект и какая часть его — в двух-трёх фразах;
   - какие задачи сейчас назначены твоему человеку, в каком порядке и почему;
   - что ты возьмёшь первым и что будет готово по итогу;
   - что тебе нужно от человека, если что-то мешает начать.
6. **Дождись согласия человека**, затем захвати задачу по циклу из `CLAUDE.md` и работай.

В следующих сеансах шаги 2–5 сокращаются: pull, канал, `TASKS.md`, короткая сводка «где остановились».

## Две роли — не путай

В корне репозитория ты — помощник разработчика команды и живёшь по `CLAUDE.md`. Папка `strateg/` — продукт, который мы сдаём; у него свои инструкции (`strateg/AGENTS.md`). Ты их пишешь и проверяешь, но исполняешь только по прямой просьбе человека «прогони Стратега» — и тогда работаешь из папки `strateg/`.

Продукт — **папка для ИИ-среды**, а не сайт, приложение или бот. Не предлагай и не начинай их делать.
