# Форматы материалов: что агент читает и как это проверено (T29)

16 ноября 2026. Только собственные материалы команды и учебные файлы.

| Формат | Чем читается | На чём проверено | Результат | Границы |
|---|---|---|---|---|
| Word `.docx` | `extract`, стандартная библиотека | Записка «Полки»; три настоящих документа команды (T15) | Текст и таблицы с метками `[абз. N]` | Старый `.doc` — пересохранить в `.docx` |
| Excel `.xlsx` | `extract` | Таблица «Полки» на 4 листа; финмодель на 6 листов (T15) | CSV по листам, номер строки сохранён | Формулы — значения, а не формулы; даты могут прийти числом; старый `.xls` — пересохранить |
| PowerPoint `.pptx` | `extract` | Презентация команды (T15) | Текст по слайдам `[слайд N]` | Текст в картинках не читается |
| HTML, CSV, TSV, текст | `extract` | Выписки и обращения «Полки», тесты | Текст без разметки и скриптов; CSV в UTF-8 | — |
| **PDF** | `extract`, собственное чтение на стандартной библиотеке (`tools/pdftext.py`); `pdftotext`, если установлен, — запасной путь | PDF из Chrome (кириллица, таблица, 2 страницы); черновик описания для жюри (генератор отчётов, 6 страниц, ~7 500 знаков); PDF системной печати macOS; тесты | Весь текст, кириллица, символы ₽ и «—», разбивка `[стр. N]`; ячейки таблиц разделены пробелом | Скан — текста нет, агент предупреждает и разбирает изображение средствами среды; зашифрованный — ошибка с подсказкой; текст во вложенных формах и редкие кодировки не читаются; таблицы теряют разметку столбцов |
| Изображения: снимки экрана, фото | Средства ИИ-среды (Claude Code, Cursor читают изображения) | Снимок экрана оформления «Полки» в прогонах 1–3; сверщик фактов по нему же | Видимый текст и расположение прочитаны верно; агент описывал только видимое | Мелкий или нечёткий текст — риск ошибки; навык `ux` требует записывать только видимое |
| Аудио, видео | **Не поддерживается** | — | — | Ни скрипт, ни Claude Code сами не расшифровывают речь. Нужна готовая расшифровка (её агент разберёт как текст) или внешний сервис, который мы не подключали |

## Почему PDF читается без внешних программ

Отчёты, исследования и презентации чаще всего приходят в PDF. До T29 скрипт читал его только через `pdftotext`, которого нет на обычном Mac и Windows, а Claude Code на этом Mac тоже не открыл PDF без дополнительного пакета. Теперь `extract` читает PDF сам, с номерами страниц, и цитата из PDF проверяется так же, как из Word (тест `test_pdf_pages_cyrillic_and_quote`).

## Найдено и исправлено при проверке

| Находка | Исправление |
|---|---|
| Chrome режет слова на куски сдвигами — появлялись лишние пробелы внутри слов | Догадки о пробелах по сдвигам включаются, только если своих пробелов на странице почти нет |
| Генератор отчётов кодирует потоки в ASCII85 — страницы выходили пустыми | Добавлено ASCII85 |
| Системная печать macOS пишет латиницу в Mac Roman — тире превращалось в «Ñ» | Учитывается кодировка шрифта |
| Ячейки таблицы из Chrome склеивались | Новая текстовая матрица на той же строке — пробел |

## Стоимость

Чтение файлов скриптом бесплатно и не расходует модель. Изображения читает модель среды — это обычный расход сеанса (`bench/runs/passports.md`).
