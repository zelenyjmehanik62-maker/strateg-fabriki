# Паспорта прогонов: время и расходы (T27)

Посчитано 16 ноября 2026 командой `python3 tools/strateg.py usage <журнал>` по журналам сеансов Claude Code. Цены — публичный прайс-лист Claude API на 3 ноября 2026 (`strateg/tools/prices.json`).

## Как считается

- **Токены — точные.** Claude Code пишет у каждого ответа модели: обычный ввод, запись в кэш, чтение из кэша, вывод. Команда суммирует их по моделям; повторные строки одного ответа не удваиваются.
- **Деньги — по прайс-листу.** Ввод, вывод и чтение кэша — по цене модели; запись в кэш — 1,25 цены ввода (5-минутный кэш) или 2 цены (часовой); поиск через API — $10 за 1000 запросов. Это столько, сколько прогон стоил бы через API по публичным ценам. На подписке пользователь платит не за токены, на договорных ценах — иначе.
- **Время модели** — сумма промежутков между записями журнала среды без пауз дольше 20 минут. Это время, когда сеанс работал, включая ожидание страниц и инструментов, — не время на чтение пользователем.
- **Время человека не измерено.** Известно только число его ответов.

## Что из этого следует

- **Путь агента от запроса до стратегий стоит 1,7–4,0 доллара по прайс-листу** при 6–36 минутах работы модели и 2–3 ответах человека. Дороже всего — исследование в сети: оно длиннее, и каждый следующий шаг перечитывает накопленное.
- **Почти весь расход — чтение кэша.** Агент много раз перечитывает свои инструкции и материалы проекта; кэш делает это в 20–40 раз дешевле обычного ввода. Без кэша тот же прогон стоил бы в разы дороже.
- **Обычный чат дешевле в 2–3 раза** и при этом работал на более дорогой модели (Fable 5.2 против Opus 5.5 у агента). Это совпадает с выводом сравнения: за проверяемость и полноту агент платит временем и деньгами.
- **Сверка фактов на Haiku почти бесплатна** — 2 цента против 53 на Opus при том же качестве на стенде.

## Что не покрыто

- **Поиск в сети — частично.** До 17 ноября `usage` не видел поисков, сделанных инструментом среды: они идут отдельными запросами, которых нет в расходе ответа модели. Теперь команда считает вызовы поиска и загрузки страниц и добавляет цену поисков по прайс-листу (у `semya` — 12 поисков, $0,12). Токены, которые среда тратит на обработку результатов поиска и страниц, в журнал не попадают и не измерены.
- **Служебные вызовы среды** (сжатие истории, вспомогательные модели самой среды) в журнал агента не попадают.
- **Первый полный прогон «Полки»** (14 ноября): его журналы среда уже удалила, расход не восстановить. Известен только объём — около 270 тыс. токенов в последнем контексте.
- **Курс рубля** не задан: итог в долларах. Чтобы перевести, укажите курс в `strateg/tools/prices.json` с датой и источником.

## Как посчитать свой прогон

В Claude Code журнал сеанса лежит в `~/.claude/projects/<путь к папке, где / заменены на ->/<номер сеанса>.jsonl`. Самый свежий файл в папке — текущий сеанс. Из папки `strateg/`:

```bash
python3 tools/strateg.py usage ~/.claude/projects/<папка>/<сеанс>.jsonl --project <имя проекта>
```

С `--project` итог попадёт в журнал проекта, и `cost` покажет его рядом со временем. Журналы Codex и Cursor устроены иначе и этой командой не читаются.
