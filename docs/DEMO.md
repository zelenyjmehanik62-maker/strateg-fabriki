# Демо T8 — комплект для живого прогона под запись

Ратмир-Claude (за Нику), 17 ноября 2026. Решение ведущего — «Журнал решений» в `TASKS.md` от 17.11.
Внутренний документ команды, жюри не отправляется. Сценарий ролика — `submission/video-script.md`.

## Что показываем и как подписываем

- **Задача:** собственная задача команды на открытых данных — подписка «Семейная безопасность» для пожилых у **условного** оператора связи. Бриф МегаФона не опубликован; задание разрешает в этом случае свою задачу. В ролике и PDF так и пишем: «собственная задача команды», не «бриф МегаФона» и не «данные МегаФона».
- **Режим:** полный — шесть шагов с остановками. Быстрый режим по этой же теме уже лежит примером `projects/semya/`; сравнение «быстрый против полного на одном вопросе» — честная и полезная деталь для PDF.
- **Кто ведёт:** Ратмир играет руководителя продукта и сам отвечает агенту. Помощник в корне не подсказывает агенту и не правит файлы проекта во время прогона.
- **Проект:** агент назовёт его сам при создании. Если предложит имя — попроси `demo`. Дальше в документах — `projects/demo/`.

## Перед записью — 10 минут

1. В корне репозитория: `git pull --rebase`. Запиши номер коммита: `git log -1 --format=%h` — он пойдёт в паспорт записи.
2. Проверь, что тесты проходят: `python3 -m unittest discover -s strateg/tools -p "test_*.py"`.
3. Включи «Не беспокоить», закрой мессенджеры, почту, личные вкладки. В кадре не должно быть имени пользователя компьютера и путей вида `/Users/...` крупным планом — по возможности.
4. Окно Claude Code — на весь экран, шрифт крупнее обычного (Cmd + «+» два-три раза), чтобы текст читался на записи.
5. Запись экрана: **Cmd + Shift + 5** → «Записать весь экран» → «Параметры»: сохранить на рабочий стол, микрофон — **выключен** (озвучка отдельно, при монтаже). Проверь 10 секунд записи — открывается ли файл.
6. Открой **новое** окно Claude Code в папке `strateg/` (не в корне репозитория). Модель — та, на которой хочешь показывать; запиши её название из интерфейса.
7. Начни запись, потом отправь первое сообщение.

## Первое сообщение (вставить целиком)

Запрос нарочно размытый — так агент покажет, как уточняет постановку.

```text
Я руковожу цифровыми продуктами у оператора связи. Думаем запустить платную подписку
для пожилых: защита от мошеннических звонков, где сейчас находится человек, кнопка SOS.
Через две недели продуктовый комитет ждёт от меня записку: запускать или нет.
Внутренних данных у меня не будет, только открытые источники. Помоги разобраться.
```

## Шпаргалка ответов на остановках

Отвечай своими словами — это не текст для чтения, а то, что «знает» руководитель. Если агент спросит то, чего здесь нет, честно отвечай «не знаю» или «реши сам по открытым данным».

| Остановка | Что, скорее всего, спросит агент | Что отвечать |
|---|---|---|
| Постановка | Цель, кто решает, срок, ограничения, что уже есть | Цель — платящие подписчики и выручка за первые 6–12 месяцев, имидж вторичен. Решает продуктовый комитет, нужна записка на 1–2 страницы. Срок — 30 ноября. Бесплатный определитель спама у нас уже есть у всех абонентов; семейного продукта с геолокацией и SOS нет. Бюджет и команду пока не назвали. Думаю, платить будут взрослые дети, а не сами пожилые. Подтверди постановку, когда она тебя устроит |
| Режим | Быстрый или полный | **Полный** |
| Материалы | Есть ли файлы; можно ли искать в сети | Файлов нет, ищи сам в открытых источниках. Если среда спросит разрешение на поиск или загрузку страницы — разреши |
| План исследования | Согласовать вопросы | Прочитай и согласуй. Хороший живой момент — добавить одно своё: «Проверь ещё, сколько берут конкуренты и что входит в бесплатные версии» |
| Варианты | Выбрать вариант | Выбирай по-настоящему, то, что убеждает тебя. **До выбора** — один раз не согласись с самым сильным выводом: «Я не согласен, мне кажется, дело в цене, а не в функциях». Агент должен показать основания, а не сразу сдаться. Это кадр «несогласие» |
| Стратегии | Утвердить | Попроси одну правку: «исправь: в рекламе не обещаем то, чего продукт ещё не умеет». Потом утверди |
| Сопровождение | Записать решение | Подтверди решение |

## Перерыв и продолжение — обязательная сцена

1. После утверждения стратегий напиши **«стоп»**. Дождись ответа, что место сохранено.
2. Останови запись (кнопка в строке меню). Закрой окно Claude Code полностью.
3. Начни **вторую** запись. Открой новое окно Claude Code в `strateg/`. Напиши только:

```text
Привет, я вернулся. На чём мы остановились?
```

Не пересказывай прошлую работу — агент должен восстановить всё сам из файлов.

4. Затем поправка к постановке (настоящая, от руководителя, — не выдуманный факт):

```text
Поправка: комитет сказал, что денег на рекламу не будет, продавать можно только
через наши собственные каналы — приложение, сайт и салоны.
```

Агент должен показать, какие выводы и части стратегий это затрагивает, вернуться к нужному шагу и переделать только его. Это кадр «изменение постановки».

5. В конце: **«статус»** — агент покажет, где мы и сколько это стоило. Останови запись.

## Чего не делать во время прогона

- Не править файлы проекта руками и не просить помощника в корне что-то «подправить» — прогон должен быть настоящим.
- Не продолжать в том же окне вместо нового чата.
- Не подсказывать агенту ответы из примера `projects/semya/`.
- Не перезапускать неудачный шаг тайком. Упало — оставляем в записи, при монтаже покажем коротко.

## Сколько это займёт

Эта же тема в быстром режиме с поиском в сети шла 36 минут работы модели (`bench/runs/passports.md`, прогон `semya`). Полный режим длиннее: шесть остановок вместо двух и подробные документы. Закладывай полтора-два часа вместе с твоими ответами и одну попытку в запасе. Ждать у экрана не обязательно — длинные шаги при монтаже ускорим с пометкой.

## Что передать помощнику после записи

- Два файла записи с рабочего стола — имена файлов.
- Ничего искать не нужно: журналы сеансов Claude Code лежат в `~/.claude/projects/`, помощник найдёт их по времени и посчитает расход командой `python3 tools/strateg.py usage … --project demo`.
- Помощник проверяет проект (`check`, `status`), коммитит `projects/demo/`, заполняет паспорт записи в `submission/recording-plan.md`, монтирует ролик по `submission/video-script.md` и пишет раздел о демо в PDF (T13).
