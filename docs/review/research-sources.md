# Источники исследований и выбор методики

Подготовлено 16.11.2026. Предложение для методики T4 и будущего живого исследования, не уже подключённая база знаний. Ни один обзор ИИ, включая Perplexity, не становится первичным доказательством: открыть исходную страницу, проверить утверждение и сохранить место. Выбор поискового сервиса и модели - отдельный измеренный выбор, не обязательное условие.

## Как выбирать данные

1. Сначала решающий вопрос: например, «потеряли ли платящих из-за цены или изменился трафик?». Затем набор данных, способный изменить выбор. Не собирать всё о цифровой экономике.
2. Оценивать **конкретный материал по шести независимым признакам**: происхождение; соответствие вопросу/сегменту; период; методика и выборка; проверяемое место; ограничения/заинтересованность. Помечать каждый как «достаточно / ограничено / неизвестно», не складывать в ложную вероятность истинности.
3. Для критичного утверждения - первичный материал и независимая сверка, если она есть. Когда её нет - прямо отметить; это не повод выдумать второй источник.
4. Сохранять заголовок, автора/ведомство, URL, дату публикации и получения, период, географию, единицу, базу, таблицу/страницу, короткую выписку, формулу и ограничения. Использовать существующие `source --note` и `where`; не вводить несовместимый формат без ведущего.
5. При конфликте показывать обе версии и причины: разные годы, базы, география, методики. Не усреднять несопоставимые числа. Не путать прогноз и факт.
6. Обновление задавать по риску: тариф - повторно перед решением, квартальный показатель - по выпуску, методика - при смене определения. Нет универсального «свежее месяца = надёжно».
7. Если источник недоступен - статус «не получен», альтернативный разрешённый источник или вопрос человеку. Поисковый фрагмент не выдавать за прочитанную таблицу.

Пример карточки для будущей записи, **не факт реального рынка**:

> Вопрос → показатель X → конкретная таблица/строка → значение и база → период/регион → ограничение → какое решение изменится. Если хотя бы период или база неизвестны, не делать точный расчёт рынка.

## Методики: выбирать по вопросу

Это предложенная маршрутизация, не утверждение о наполненной `knowledge/`. Нужны короткие процедуры и пробные результаты, а не список известных названий.

| Вопрос | Метод | Минимальный полезный результат и проверка |
|---|---|---|
| Какую работу и в какой ситуации решает человек? | JTBD и исследовательские интервью | Прошлый конкретный эпизод, альтернатива, барьер, свидетельства за/против. ИИ-респондент не заменяет людей |
| Где человек теряется? | CJM и воронка | Фактические шаги, наблюдаемый разрыв, события/показатели и неизвестные места; карта не дорисовывает отсутствующее |
| Откуда конкурентное давление? | Пять сил Портера | Альтернативы и экономика силы, конкретные свидетельства; вывод «сила высокая» без основания не принимается |
| Какие внешние изменения меняют решение? | PEST/PESTEL | Фактор → подтверждённое изменение → механизм влияния → сценарий/ранний сигнал. Не общая справка о стране |
| Как создаются ценность и доход? | Business Model Canvas / Value Proposition | Связанные сегменты, задачи, предложение, каналы, доходы/затраты и неподтверждённые блоки. Официальная основа - [Strategyzer](https://www.strategyzer.com/library/the-business-model-canvas); канва не доказательство спроса |
| Что действительно является преимуществом? | SWOT/TOWS после исследования | Каждый пункт связан с фактом/гипотезой; из сочетаний следуют варианты действий. Не использовать вместо сбора данных |
| Как выбрать разные направления? | Сравнимая матрица альтернатив | Польза, затраты, риски, обратимость, неизвестное; минимум три разных варианта, статус-кво и закрытие. Веса/чувствительность согласует руководитель |
| Может ли экономика сойтись? | Unit economics и сценарии | Маржа, CAC/LTV при подходящей модели, горизонт/дисконт/возвраты и диапазоны. Без исходных данных - чувствительность, не точный LTV |
| Проверяет ли опыт гипотезу? | Контрольный эксперимент или обоснованный квазиэксперимент | Основной показатель, база, минимально полезный эффект, сравнение, окно и последствия. Мощность/выборку считать, не назначать по желанию |

Не заполнять все девять методик в каждом запросе. В постановке выбрать 1-3, которые реально влияют на решение, и назвать причину выбора. Методическая библиотека и исполнение навыков меняются в зоне Влада после согласования, этот файл их не перезаписывает.
