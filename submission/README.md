### Пересборка PDF

Это инструменты подготовки описания; зависимости продукта в `strateg/` не меняются. Для PDF автору нужен ReportLab; для новых PNG - Node.js, Playwright и Chrome; для визуальной проверки - Poppler. Если сохранённые PNG подходят, для сборки достаточно первого действия ниже. Скрипт использует Arial из Windows.

Из корня репозитория:

```powershell
python -X utf8 submission/build_description.py
```

Чтобы заново снять доказательства: `python -X utf8 submission/build_description.py --prepare`, затем задать `CODEX_NODE_MODULES` путём к каталогу с установленным `playwright`, выполнить `node submission/capture_evidence.cjs` и пересобрать PDF. Исходники PNG - сохранённые HTML с фрагментами TXT; полный вывод не сокращается.
