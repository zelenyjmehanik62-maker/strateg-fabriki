### Сборка

Нужен только Google Chrome или Chromium, дополнительные пакеты не нужны. Из корня репозитория:

```bash
python3 submission/build_pdf.py              # PDF из description.md
python3 submission/build_pdf.py --evidence   # сначала заново снять снимки вывода команд
```
