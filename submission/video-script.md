## Что должно стать понятно жюри

Руководитель приносит неоднозначный запрос. Агент собирает основания, отделяет факты от гипотез, показывает содержательно разные варианты и помогает подготовить две согласованные стратегии. Выбор остаётся человеку. В новом чате работа продолжается из файлов; при изменении основания видно, какие решения надо пересмотреть.

## Команды для подтверждающих кадров

Выполнять из `strateg/`. Значение `demo-megafon` применять только после T8; до этого для репетиции использовать существующий проект `polka`. `-X utf8` нужен для надёжного вывода кириллицы и ₽ на проверенной Windows.

```powershell
python -X utf8 tools/strateg.py status demo-megafon
python -X utf8 tools/strateg.py check demo-megafon
python -X utf8 tools/strateg.py review demo-megafon
python -X utf8 tools/strateg.py cost demo-megafon
```

После T8 выбрать настоящие идентификаторы и вписать их в [план кадров](recording-plan.md). Для них выполнить `show demo-megafon E-<номер>` и `impact demo-megafon E-<номер>`; угловые скобки не копировать в терминал. Перед записью проверить, что команды поддерживаются текущей версией и данные относятся к той же сессии.

## Как честно сократить длинный проход до 10 минут

- Сохранять исходную запись целиком. Допускается убрать ожидание и повторяющееся чтение, но помечать ускорение/склейку и показывать реальное время по журналу.
- Не склеивать вопрос из одного прогона с ответом из другого и не выдавать подготовленный файл за только что созданный.
- Результаты готового прогона разрешено открыть отдельно с подписью «результат ранее записанного шага». Полное исследование не обязано помещаться в экранные девять минут.
- Продолжение в новом чате показать настоящим переходом; не имитировать его внутри прежнего разговора.
- Если инструмент упал, оставить краткий кадр ошибки и повтор/ограничение. Не изображать успешное действие поверх неудачного.

## Что пока нельзя произносить

- «Мы быстрее и дешевле обычного чата». Единственный исторический учебный замер показал обратное по времени и токенам; денежный расход не измерен.
- «86% выводов верны». В сравнении измерена доля строк с цифрами со ссылкой, а не истинность утверждений.
- «Демо МегаФона готово» до T8, «все среды проверены» до соответствующих прогонов, «расходов нет» при неполном журнале.
- «Любая гипотеза, выданная за факт, обнаруживается». Проверка использует структуру и текстовые маркеры; смысловые ошибки возможны.
- «Модельные интервью подтвердили спрос». Они дают только гипотезы.
